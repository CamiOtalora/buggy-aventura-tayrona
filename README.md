# Buggy Aventura Tayrona — Mini web

Página de una sola pantalla, pensada para celular, del tour en buggy "Del monte al mar" (Moto Viajeros · Buggy Aventura Tayrona, El Rodadero, Santa Marta).

- `index.html` — toda la página (estilos y código incluidos).
- `img/` — logo, fotos, fondos y QR de pago.

## Cambios frecuentes

Todo está en `index.html`:

- **Precio**: buscar `150.000` (textos) y `PRECIO = 150000` (cálculo de la reserva).
- **WhatsApp de reservas**: `WA = '573239301842'` y los enlaces `wa.me/573239301842`.
- **Máximo de personas por reserva**: `MAX = 10`.
- **Llaves de pago**: buscar `data-copy=`.
- **Horarios**: bloque `class="hours"` y los botones `data-hora=` de la ventana de reserva.

Publicada con GitHub Pages desde la rama `main`.
